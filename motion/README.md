# motion/ · Kedinin beden dili

**Sorumlu:** Reşat · **Tasarım:** Tuğra

Duyguları beş eklemin hareketine çeviren pozlar, animasyonlar ve ekrandaki simülatör (Tkinter). Girdisi Sözleşme C1 formatındadır.

**Başlangıç:** [Reşat için Başlangıç Rehberi](https://claude.ai/code/artifact/f6f8d368-a12b-48fb-9626-5e73e70f0614). İlk dosya: `motion/simulator.py`.

Pozlar ve animasyonlar Tuğra ile birlikte tasarlanır: Tuğra hareketi tarif eder veya çizer, Reşat koda çevirir.
