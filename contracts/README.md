# contracts/ · Sözleşmeler

**Sorumlu:** Ferhat

Modüllerin birbirine gönderdiği mesajların Python'daki tanımları burada (Pydantic modelleri). Yanlış formatta bir mesaj gönderilirse program anında hata verir; böylece hatalar entegrasyon gününde değil, yazarken yakalanır.

Bu klasördeki bir dosyayı değiştirmeden önce [Arayüz Sözleşmeleri](https://claude.ai/code/artifact/bf0da636-6bd1-4f66-9efb-c4f3d0124282) dokümanına yorum yaz. Değişikliği Ferhat onaylar ve sürüm numarası artar.
